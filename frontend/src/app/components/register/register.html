Terminos de uso y tratamiento de datos personales

Uso responsable de Q-LESS

Al crear una cuenta en Q-LESS autorizas el uso de tus datos personales para la gestion de usuarios, pedidos, carrito, historial de compras, foto de perfil, conversaciones con Q-bot y comunicacion relacionada con el servicio de papeleria virtual.

Tratamiento de datos personales

La informacion registrada sera usada unicamente para permitir el funcionamiento del sistema, validar tu identidad dentro de la plataforma, administrar pedidos y mejorar la experiencia de uso. Q-LESS no solicita datos sensibles innecesarios ni comparte tu informacion con terceros ajenos al servicio, salvo cuando sea requerido para procesos operativos como pagos, soporte o cumplimiento legal.

Compromisos del usuario

Como usuario te comprometes a ingresar informacion veraz, proteger tus credenciales de acceso y usar la plataforma de forma responsable. Puedes solicitar la actualizacion o eliminacion de tu informacion desde las opciones de perfil disponibles en el sistema.
